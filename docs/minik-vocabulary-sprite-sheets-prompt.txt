MINIK VOCABULARY SPRITE-SHEET IMAGE GENERATION PROMPT
=====================================================

You are generating educational vocabulary artwork for the Minik child-learning app.

IMPORTANT WORKFLOW
- Generate ONE sprite sheet per request, using the requested sheet section below.
- Do not generate separate image files for the individual objects.
- Return the sprite sheet itself as the image output.
- Use a true transparent background (alpha), not white, gray, checkerboard, or a fake transparency pattern.

GLOBAL ART DIRECTION
- Friendly, polished, playful educational illustration suitable for children.
- Bright, clean, modern Minik personality: soft rounded forms, expressive but not babyish.
- Clear object identity is more important than decorative detail.
- Consistent visual language across all sheets.
- No text anywhere in the artwork.
- No letters, numbers, logos, captions, labels, watermarks, UI, signs with readable writing, or brand marks.
- No cell borders, no frames, no boxes, no background panels.
- Avoid photorealism; use clean illustrated objects/scenes.
- Do not add unrelated decorative objects.

LAYOUT RULES
- Use a 4 x 4 logical grid for sheets with 16 cells.
- For the final partial sheet, preserve the same 4-column grid and leave unused cells fully transparent.
- Cells are numbered left-to-right, top-to-bottom: 1..16.
- Put exactly ONE requested vocabulary concept in each assigned cell.
- Keep every concept entirely inside its own cell.
- No object may overlap or touch another cell.
- Leave clear transparent gutters between cells.
- Center each object/scene in its cell.
- Keep object scale visually consistent while allowing naturally long/wide items to fit.
- Preserve all disconnected parts belonging to one concept inside its cell.

CROPPING / DOWNSTREAM PROCESSING
- Do NOT add deliberate transparent padding around the object inside its cell beyond what is needed to avoid clipping.
- After generation, each cell will be cropped again using the non-transparent alpha bounding box.
- Therefore the artwork itself must be complete and must not touch the cell boundary.
- Do not use a drop shadow that extends far from the artwork; subtle contained shading is fine.

AMBIGUITY RULES
- Follow the visual brief exactly.
- When 'avoid ambiguity with' is provided, make the requested concept clearly distinct from those concepts.
- For abstract-looking items that remain in this manifest, use the concrete composition described in the brief rather than symbolic text.

DO NOT GENERATE NATIONAL FLAGS HERE.
Country/flag assets are handled separately as trusted non-generative assets.

HOW TO USE THIS PROMPT
1. Start a new regular ChatGPT conversation with image generation enabled.
2. Paste this whole prompt once.
3. Then ask: 'Generate sheet_001 now.'
4. After reviewing it, continue sheet_002, sheet_003, etc.
5. Do not change the cell mapping between generations.
